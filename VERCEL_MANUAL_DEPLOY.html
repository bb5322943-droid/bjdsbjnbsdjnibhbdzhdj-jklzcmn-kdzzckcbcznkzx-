🚀 Fusion ERP Deploy

Vercel Manual Deploy - Eng Oson Yo'l

📊 Hozirgi Holat:

✅ Git repository yaratildi
✅ Barcha fayllar commit qilindi
✅ Build tayyor (dist/)
✅ Vercel proyekt mavjud: orbis
❌ SSL muammosi tufayli CLI ishlamayapti

⚠️ Muammo

Sizda korporativ tarmoq/firewall SSL sertifikat muammosi bor. Shuning uchun Vercel CLI va npm install ishlamayapti.

✅ Yechim

GitHub orqali deploy qilsangiz, Vercel o'z serverlarida build qiladi va SSL muammo bo'lmaydi!

📋 Deploy Qilish (3 ta usul):

1

Hozirgi build'ni redeploy (ENG TEZKOR)

Allaqachon tayyor build'ni deploy qiling:

1. Vercel.com ga kiring →
2. "orbis" proyektini oching
3. "Deployments" tab
4. "..." → "Redeploy" bosing

⏱️ Vaqt: 2 daqiqa

2

GitHub orqali (TAVSIYA QILINADI)

A. GitHub'da repo yarating:
GitHub'da Repo Yaratish →

B. Terminal'da push qiling:

git remote add origin https://github.com/YOUR_USERNAME/fusion-erp.git
git push -u origin main

C. Vercel'da ulang:
Vercel → orbis → Settings → Git → Connect Repository

⏱️ Vaqt: 10 daqiqa
🎁 Bonus: Har safar git push = avtomatik deploy!

3

GitHub Desktop (GUI)

Agar terminal bilan ishla qilish qiyin bo'lsa:

1. GitHub Desktop yuklab oling →
2. O'rnating va login qiling
3. "Add Local Repository" → loyiha papkasini tanlang
4. "Publish repository" bosing
5. Vercel'da GitHub'ga ulang

⏱️ Vaqt: 15 daqiqa (birinchi marta)

🎯 Deploy bo'lgandan keyin:

URL: https://orbis.vercel.app
API test: https://orbis.vercel.app/api/ping

⚙️ Environment Variables (MAJBURIY!)

Vercel Dashboard → Settings → Environment Variables'da qo'shing:

• JWT_SECRET (random 64 char)
• JWT_REFRESH_SECRET (random 64 char)
• ADMIN_EMAIL
• ADMIN_PASSWORD
• DATABASE_URL (Vercel PostgreSQL)
• NODE_ENV=production
• ALLOWED_ORIGINS=https://orbis.vercel.app
