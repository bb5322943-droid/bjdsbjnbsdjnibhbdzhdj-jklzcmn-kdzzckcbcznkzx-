💾 DATABASE (KEYINGI QADAM)
───────────────────────────────────────────────────────────────

⚠️  Hozircha database yo'q - keyingi qadamda qo'shamiz

VARIANT 1: Vercel Postgres
───────────────────────────
1. Vercel Dashboard → Storage → Create Database → Postgres
2. "Postgres" ni tanlang
3. Avtomatik environment variable qo'shiladi:
   - DATABASE_URL (avtomatik)

VARIANT 2: Supabase (FREE)
───────────────────────────
1. supabase.com → New Project
2. Settings → Database → Connection string
3. Qo'lda qo'shing:

Name: DATABASE_URL
Value: postgresql://postgres:[YOUR-PASSWORD]@db.xxx.supabase.co:5432/postgres

VARIANT 3: Neon (Serverless PostgreSQL)
────────────────────────────────────────
1. neon.tech → New Project
2. Connection string'ni copy qiling
3. Qo'lda qo'shing:

Name: DATABASE_URL
Value: postgresql://user:pass@ep-xxx.us-east-2.aws.neon.tech/dbname
