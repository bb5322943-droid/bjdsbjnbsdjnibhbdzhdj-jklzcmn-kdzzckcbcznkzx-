Men loyihani deploy qilishga tayyor qildim! Endi siz 3 ta oddiy qadamni bajaring:

═══════════════════════════════════════════════════════════
📦 QADAM 1: GITHUB REPOSITORY YARATING (2 daqiqa)
═══════════════════════════════════════════════════════════

1. Bu havolani oching: https://github.com/new

2. Sozlamalar:
   ✓ Repository name: fusion-erp
   ✓ Public yoki Private (istagan)
   ⚠️ "Add README" - BOSHMANG!
   ✓ "Create repository" tugmasini bosing

3. Terminalda ishga tushiring:

   git remote remove origin
   git remote add origin https://github.com/SIZNING_USERNAME/fusion-erp.git
   git push -u origin main

   (SIZNING_USERNAME ni o'z GitHub username'ingiz bilan almashtiring!)

═══════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════
✅ QADAM 3: CORS SOZLANG (1 daqiqa)
═══════════════════════════════════════════════════════════

Deploy tugagach:

1. Vercel URL'ingizni ko'chirib oling (masalan: https://fusion-erp-xyz.vercel.app)

2. Vercel dashboard'da:
   Settings > Environment Variables

3. Yangi variable qo'shing:
   Name: ALLOWED_ORIGINS
   Value: https://fusion-erp-xyz.vercel.app (o'z URL'ingiz)

4. Redeploy qiling:
   Deployments > ... (3 nuqta) > Redeploy
